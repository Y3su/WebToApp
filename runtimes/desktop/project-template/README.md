# Local Windows preview

Generated by WebToApp from a validated AppSpec. This is a customer-local,
unsigned developer project, not a store-ready application or hosted build.
Ownership entries are claims, not authenticated release authorization.

On Windows with Node 22.15.1, pnpm 11.19.0, Rust 1.89, MSVC and WebView2:

```powershell
pnpm install --frozen-lockfile
pnpm typecheck
pnpm desktop
```

The executable is
`src-tauri/target/x86_64-pc-windows-msvc/debug/webtoapp-desktop-runtime.exe`.
The generic executable/product name is intentional: display names never become
paths or build commands. Your app name appears in its window title. Keep the
adjacent `resources` directory with the executable; it contains the frozen
AppSpec.

`wta.project.json` records the canonical AppSpec SHA-256 and generated file
hashes. Regeneration requires a new output directory; files are never replaced.
This file inventory is not signed provenance or proof of reproducible binaries.
The bundled resource is a snapshot, not a reference back to the original input.

Native permissions, OAuth popups, external navigation and installers are not
enabled. Branding uses a generic icon; custom icons are not downloaded.
Requested installer formats are not built. Use only authorized HTTPS content.
Signing, customer ownership verification, platform capabilities and distribution
remain future work.

The Windows WebView uses an in-private session (cookies do not persist across
sessions) and denies browser permission requests, downloads and popups. Remote
navigation starts only after the native permission policy is installed. These
guards do not yet constitute complete production browser containment: ordinary
file-input dialogs and subresource traffic still need policy and device tests.
Other desktop operating systems fail closed until equivalent guards exist.

Third-party dependencies retain their own licenses. Preserve their required
notices and source/relinking materials before distributing built artifacts.
